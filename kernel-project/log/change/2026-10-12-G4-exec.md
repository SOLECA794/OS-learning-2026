# G4：最小命名程序源 + exec

日期：2026-10-12
依据：V2 总路线 §7「exec 语义：成功使用新现场、失败保留旧进程」+ §9「程序来源要在 exec 之前可用」。
前置：W4 进程生命周期（27b75fe）、G1 连续页复用（a966e2c）。

## 实现

- **`src/kernel/fs/programs.rs`**（RV）：命名只读程序源注册表 `name → 内嵌 ELF`，
  含 `uapp`/`uapp2`/`bad`（坏 ELF 验收用例）。路径最简解析：去前导 '/' 查表。
  G5 由 ramfs + 路径查找接管，本模块保留为 boot 程序源回落。
- **`src/kernel/syscall/exec.rs`**（RV）：`sys_execve(path, argv, envp)`——
  路径/参数从用户内存有界拷贝（copy_from_user 段校验）→ 程序源查表 → ELF 解析 →
  构建新地址空间（未发布）→ 新栈上排布 argv 字符串与指针数组 → 先 `activate` 新页表
  再 `task::exec_replace_space`（旧空间 drop 时硬件已切表）→ 重写 TrapContext
  （entry/argc/argv/新 sp）。
- **`trap.rs`**：`SYSCALL_EXECVE` 特判——成功返回后**不得再写旧现场**（现场已被替换），
  失败走普通 errno 返回路径。
- **`task::exec_replace_space`**：把当前任务地址空间一次性替换（锁内）。
- **`TrapContext::new_user_with_args`**：带 argc/argv 的 U 模式入口现场（C ABI）。
- **用户侧**：`user/src/bin/uapp2.rs`（exec 目标：写 'X' → exit(7)）；
  `uapp` 主程序新增 exec 验收段（见验证矩阵）；`user/Cargo.toml` 增 `[[bin]]`；
  Makefile `user` 目标产 `uapp.elf` + `uapp2.elf`。

## 验证矩阵（agent-run，WSL Ubuntu-24.04 + QEMU 8.2.2）

| 项 | 结果 |
|---|---|
| RV make build | PASS，e_entry=0x80200000 |
| QEMU 主链路（90s 有界） | **PASS**：`RRRRRRRR PASS`（8 轮 fork 无泄漏，wm 恒 1815）→ `E1` → `E2` → `X` → `[exit] task 0 exited with code 7` → parking |
| exec 失败① /nonexist | **-ENOENT**，旧进程保留并继续（输出 E1） |
| exec 失败② /bad（坏 ELF） | **-ENOEXEC**，旧进程保留并继续（输出 E2） |
| exec 成功 /uapp2 + argv | **换程序**：uapp2 从 `_start(argc, argv)` 进入，输出 X，exit(7) 被内核回收 |
| fault-test 回归 | PASS（受控 fatal trap，from_user=true） |
| LA make build | PASS（e_entry=0x200000）——exec/fs 模块 RV-only cfg，LA 不受影响 |

## 设计说明

- **成功不写返回值**：exec 成功后 TrapContext 已是新程序入口，handler 返回即进新程序；
  若仍写返回值会污染 a0（被 argc 覆盖的语义）。这是 syscall 层唯一"现场替换"型调用，
  trap 分发处以特判承载（V2 §7 返回动作合同）。
- **先切表再释放**：新页表含内核身份映射，activate 后当前执行安全；随后 drop 旧空间
  释放页表树与用户页，避免释放仍被 satp 引用的页表。
- **argv 栈布局**：字符串自栈顶向下连续排布（含 null），指针数组（含 NULL 结尾）在下方，
  sp 指向指针数组首元素（16 字节对齐），`_start(argc, argv)` 以 C ABI 接收。
- **errno 常量**：沿用现有负数 errno 风格（ENOENT=-2、ENOEXEC=-8、EFAULT=-14、ENOMEM=-12、E2BIG=-7）。

## 残留风险

- envp（execve 第 3 参）暂忽略（传 0）；argv 上限 16 项、单参 ≤256 字节、路径 ≤128 字节。
- 用户栈仍为单页（4KB）：参数过大返回 E2BIG/EFAULT，不越界。
- 程序源为编译期内嵌静态表：G5 ramfs 落地前不支持任意路径。
- LA 侧 exec 未实现（返回 ENOSYS），与 V2 排期一致（功能先 RV 后 LA）。

## Architecture Friction Scan

Safe：无阻断摩擦。
Euclid（记录不修）：exec 后不主动刷 TLB 之外的所有缓存/分支预测状态（RISC-V 无历史
依赖，当前路径验证通过）；G5 FD 表落地时 exec 需重置 fd 继承语义。
