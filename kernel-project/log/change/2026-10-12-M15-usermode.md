# M1.5：用户态首闭环（RV 单任务）

日期：2026-10-12
范围：W2 用户态链路的前置里程碑——规划书 W2「RV 用户态 + 内核栈 + 静态 ELF + write/exit」的验收打通。
前置：M1（trap 骨架、MemorySet、内核分页）已通过双架构 QEMU 验证。

## 目标

在 RV QEMU 上跑通：用户程序经 sscratch 协议进出内核态，`write(1, ...)` 输出、`exit(0)` 退出并由内核记录停机。

## 实现边界（boundary M1.5 的落地）

- `user/`：独立 no_std crate uapp（静态 RV64 ELF，链接基址 0x10000，`_start` 内联 ecall）。
- `src/kernel/elf.rs`：最小 ELF64 解析器（仅 ehdr/phdr + PT_LOAD，拒绝非 ELF/非 RV64/越界/重叠文件区间，零第三方依赖）。
- `src/kernel/mm/memory_set.rs`：`new_user`（内核映射 + 用户段 + 用户栈）、`load_elf`（逐页拷内容 + bss 清零）、`insert_kernel_mapping`（从 new_kernel 抽出复用）。
- `src/arch/riscv64/trap/`：entry 汇编 sscratch 切换（用户态/内核态来源判定）+ 独立 `__riscv64_trap_restore` 符号（trap 返回与首次进入用户态共用）；trap 处理期间置 sstatus.SUM=1，恢复写回保存值自动清除；`TrapContext::new_user`；`set_user_scratch` / `restore_from`。
- `src/kernel/syscall/mod.rs`：`write`（fd=1 校验 + copy_from_user 段边界校验 + EFAULT/EBADF 受控）+ `exit`（记录退出码后停机）。
- `src/kernel/mod.rs`：`init_user`（include_bytes uapp → 解析 → 建用户空间 → 拷段 → 激活页表 → 内核栈顶放 TrapContext → sscratch=栈顶 → restore 进 U 模式）。
- LA 侧：`new_user` 构造器 + `set_user_scratch`/`restore_from` 占位（功能后置，仅保证双架构编译）。
- Makefile：`user` 目标（显式 --target + `$(CURDIR)` 绝对链接脚本路径；补 .PHONY 修复「目标名与 user/ 目录同名导致 up-to-date」陷阱）。

## 开发中修掉的四个真问题

1. **user 目标被 make 判定 up-to-date**：目标名与 `user/` 目录同名，未声明 .PHONY → 首次集成时 uapp.elf 从不生成，include_bytes 编译失败。修：DEFAULT_PHONY 补 user。
2. **user crate 的 .cargo/config.toml 不被 --manifest-path 模式发现**（cargo 从 CWD 找配置）：target/rustflags 全部丢失 → 以 host 目标编译，inline asm 报 `invalid register a0`。修：Makefile 显式 `--target` + RUSTFLAGS。
3. **链接脚本相对路径失效**：rustc 链接时工作目录切到临时目录，`-Tuser/user.ld` 找不到。修：`-T$(CURDIR)/user/user.ld` 绝对路径；同时去掉 `-nostartfiles`（裸机目标无 crt，rust-lld 不认该 GNU ld 参数）。
4. **用户 LOAD 段共享页 → MemorySet Overlap panic**：rustc 小程序 `.text`(end=0x1004c) 与 `.rodata`(start=0x1004c) 共享 0x10000 页，逐段 insert 冲突。修：`merged_user_ranges` 按页合并重叠/相邻区间（权限并集），内容仍按原始段 `load_elf` 拷贝。

## 残留风险（登记）

- `copy_from_user` 以段边界校验为准（'static 延长借用）；M1.6 换逐页 PTE 权限查询（boundary §4 已登记）。
- 共享页合并取权限并集（宽松）：若未来 data(RW) 与 text 共享页会得到 R+W+X 页。M2 逐页 PTE 精确权限时收窄。
- 用户态非法访问（未映射页/0 页/NULL）当前会走 fatal 停机路径（受控但未区分用户 fault 与内核 fault）。M2 建立用户任务时区分并转 SIGSEGV 语义。
- LA 用户态功能未实现（占位 stub），仅双架构编译通过。W9-10 排期对齐 LA 限定用例。
- uapp panic_handler 为 loop{}（write 返回负值时静默死循环）——受控但不可观测，M2 换打印 + 退出。
