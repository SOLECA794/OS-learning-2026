# G5 小 shell：ls/cat/run + 固定输入脚本 /cmds.txt（可脚本演示）

日期：2026-10-12
依据：V2 总路线 §9「基础 shell 范围」合同：列目录 / 读文件 / 启动程序 / 等待退出；
自动测试用固定输入脚本 + ready 标记；不凭提示符宣称兼容 BusyBox。
前置：G5 ramfs+FD（dd660f5）。

## 实现

- **`user/src/bin/shell.rs`**（新建）：no_std 用户程序。命令集：
  `ls`（openat("/")→Dir fd + getdents64 循环列名，reclen 来自 dirent64 偏移 16）、
  `cat <path>`（openat + read 循环到 EOF 原样输出）、`run <path>`
  （fork→子 execve→父 wait4 打印 `[exit] code=N`）；未知命令 `sh: unknown: <cmd>`。
  入口 `_start`：openat("/cmds.txt") 读全量 → 按行执行（每行前缀 `S$ `）→
  `shell: done` + exit(0)。交互 console read 未实现（G5 残留风险，脚本驱动满足
  V2 §9「固定输入脚本」；不宣称兼容 BusyBox）。
- **`user/Cargo.toml`**：注册 `[[bin]] shell`。
- **`Makefile`**：`USER_SHELL_ELF`；user 目标一并 cp shell.elf；
  新增 `build-shell`（`--features $(RUST_FEATURES),uapp-shell`）与 `run-shell`。
- **`Cargo.toml`**（kernel）：新增 feature `uapp-shell = []`。
- **`src/kernel/task/mod.rs`**：boot_tasks 的 UAPP_ELF 三档 cfg
  （uapp-fault-test / uapp-shell / 默认 uapp）。
- **`src/kernel/fs/file.rs`**：`FdEntry` 增 `Dir(Arc<AtomicUsize>)` 变体（目录枚举游标）。
- **`src/kernel/fs/ramfs.rs`**：`open` 空名("/") → `FdEntry::Dir`；init 增
  验收文件 cmds.txt（`ls\ncat /hello.txt\nrun /uapp2\ncat /nonexist\nrun /nonexist\n`）。
- **`src/kernel/syscall/fd.rs`**：`sys_getdents64`（SYS=217，Linux dirent64 布局：
  d_ino/d_off/d_reclen/d_type=DT_REG/name null 终止，reclen=align(19+len,8)，
  按游标批量填、耗尽返回 0）；Dir 上 read/write → EISDIR；sys_read/sys_write
  描述符提取统一为 `Result<Option<Arc<OpenFileDesc>>, isize>` 闭包模式。
- **`src/kernel/syscall/mod.rs`**：新增常量 GETDENTS64=217。

## 过程中修掉的真问题

1. **fd.rs 闭包返回类型不一致**（shell 阶段编译错误）：sys_read/sys_write 的
   描述符提取闭包混用 `return EISDIR`（从闭包返回 isize）与 `Some(d.clone())`
   （Option<Arc>）。统一为显式 `Result<Option<Arc<OpenFileDesc>>, isize>`，
  消费侧 Ok(Some)/Ok(None)/Err 三分支；Dir→EISDIR 语义并入同一模式。
2. **kernel Cargo.toml 未声明 uapp-shell feature**（make build-shell 编译错误）：
   `[features]` 补 `uapp-shell = []`。
3. **sys_write 结尾残留旧 Option 分支**（上一条修复过程中的残留）：换段后
   `match ramfs::write_at(...)` 仍带 `Some/None` 分支 → 类型不匹配；清为
   `Ok(_) => len as isize, Err(e) => e`。

## 验证矩阵（agent-run，WSL Ubuntu-24.04 + QEMU 8.2.2）

- RV `make build` PASS（e_entry=0x80200000）。
- `make run-shell` 实机（timeout 60，日志 /tmp/shell-log.txt）：
  - ls 列 7 项（uapp/uapp2/bad/hello.txt/dup.txt/fork.txt/cmds.txt）；
  - `cat /hello.txt` → `hello ramfs`；
  - `run /uapp2` → `X` + `[exit] code=7`（内核日志 `[wait] reaped task 1 code 7`）；
  - `cat /nonexist` → `cat: open failed`；
  - `run /nonexist` → `[exit] code=127`（子 exec 失败 exit 127）；
  - `shell: done`；task0 exit 0 → ready queue empty, parking。
  - 断言脚本 7/7 PASS（ls7 / cat-hello / code7 / code127 / catfail / done / exit0）。
- `make test-fault` 回归 PASS（W2 内核保护区访问受控，qemu rc=124 为 timeout 预期）。
- LA `make build` PASS（e_entry=0x200000；fs/fd/shell 均无 cfg LA 侧编译通过，
  LA 用户态仍 ENOSYS）。
- `cargo fmt --check` PASS。

## 残留风险（Friction Scan）

- **Dir 枚举游标 Relaxed 原子**：单核够用；SMP 后需升级（与 OpenFileDesc 偏移同批）。
- **串口输出偶发 \x03 杂质字节**（uapp2 名称后一次出现）：QEMU serial 或用户
  getdents 缓冲区边界噪声，不影响断言；后续若复现再定位（暂记 Safe）。
- **交互 console read 未实现**：fd0 read 恒 EOF；shell 只吃脚本输入（V2 §9 已登记）。
- **getdents64 无目录层级语义**：ramfs 扁平，d_off 无树语义；G6 前不承诺路径深度。
- **fs 模块无 cfg**：LA 侧编译过但 syscall 分发仍 RV-only（沿用 G5 登记）。
