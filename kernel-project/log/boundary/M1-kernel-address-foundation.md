# M1 kernel/mm 地址基础边界

## 本轮范围

- 在 `kernel/mm` 定义物理地址、虚拟地址、物理页号、虚拟页号和 4 KiB 页常量。
- 从链接器符号构造并检查内核 ELF 的 text、rodata、data、bss 与 boot stack 布局。
- 两个架构的链接脚本只负责导出各段边界，不承载通用内存管理策略。

## 明确不做

- 不探测可用物理内存上界。
- 不实现物理页分配器。
- 不创建或切换页表，不开启分页。
- 不决定 RISC-V Sv39 或 LoongArch 页表项编码。

## 后续分层

- `kernel/mm`：地址空间、映射、页分配和通用权限语义。
- `arch/riscv64`、`arch/loongarch64`：页表项编码、根页表寄存器、TLB 操作。
- 平台层：从 DTB、固件或板级配置提供 RAM 与 MMIO 范围。

## 完成标准

- 两个架构均能编译并链接。
- ELF 中包含完整且有序的内核段边界符号。
- 启动代码只检查布局，不改变当前直址执行状态。
